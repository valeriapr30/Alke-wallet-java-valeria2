¡# 💸 Alke Wallet: ¡Tu manejas tu dinero!

¡Hola! 👋 Bienvenido a **Alke Wallet**, la app de consola que creé para que puedas revisar tu saldo, retirar o depositar tu dinero de manera rapida y sencilla 🚀

##  ¿Qué hace esta billetera?
Básicamente, todo lo que necesitas saber para manejar tu dinero:
- **Ver el saldo:** Para saber cuanto saldo dispone en su cuenta
- **Depositar:** para depositar tu dinero de manera rapida y sencilla
- **Retirar:** te permite retirar dinero de manera facil
- **Cambio de moneda:** Convierte tus dólares a CLP o Euros para asi poder manejar precio de cada moneda
